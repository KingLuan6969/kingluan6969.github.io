NetSweep v1.0.0

LAN / IP Network Scanner

Sweep your local network — or a remote machine network over VPN — and list every connected device in seconds. Single self-contained .exe.

  • Parallel scanning — a full subnet swept in seconds.
  • Adapter auto-detect — IP and subnet filled from your active card.
  • Offline vendor lookup — embedded IEEE database, industrial makers included.
  • Works over VPN — names Siemens & Rockwell gear via EtherNet/IP + S7.
  • CSV + PDF export and per-device Wake-on-LAN.
Windows 10/11 · self-contained, no install · run as administrator for full MAC/vendor detection.

HMI Translator v1.0.0

Bulk TIA / WinCC text translation

Translate an Excel export of TIA Portal / WinCC project texts with DeepL — placeholders protected, over-length flagged, every save validated before re-import.

  • Placeholder-safe — %d, {0}, tags & breaks restored exactly.
  • Length budget — over-length text flagged, never truncated.
  • Memory & library — approved edits reused, never re-charged.
  • Glossary sync for consistent terminology across projects.
  • Validated save — write → re-open → cell-for-cell check.
Windows 10/11 · requires a DeepL API key (free tier available) · per-PC activation · optional Claude key for shorten-to-fit.
